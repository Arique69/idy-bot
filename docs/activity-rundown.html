Discord Activity

Rencana implementasi lengkap untuk menambahkan Discord Activity ke bot gacha yang sudah ada.

Status Planning
Estimasi 2–4 Minggu
Total Cost Rp 0 / bulan
Kompleksitas Medium–High
01

Arsitektur Sistem

Discord Client ├── Bot (slash commands, gacha) │ └── runs on VPS (Python + discord.py) │ └── exposes FastAPI → /api/user/{id}/collection │ └── Activity (iframe game) └── hosted on Vercel (free) ├── Discord Embedded App SDK └── fetch() → VPS API → ambil koleksi kartu user
02

Fase Implementasi

Phase 1
Setup & Developer Portal
Konfigurasi Discord Developer Portal dan environment awal.
  • Enable Activity di Discord Developer Portal → aplikasi yang sama
  • Set URL Mapping di Portal: / → localhost:3000 (dev) / vercel.app (prod)
  • Install Discord Embedded App SDK: npm install @discord/embedded-app-sdk
  • Buat project Vite/React baru untuk Activity
~2 hari
Phase 2
FastAPI di VPS
Tambahkan API endpoint di VPS agar Activity bisa ambil data koleksi.
  • Install FastAPI + Uvicorn di VPS
  • Buat endpoint GET /user/{discord_id}/collection
  • Buat endpoint GET /user/{discord_id}/stats
  • Jalankan di port berbeda (misal :8000), pastikan tidak bentrok bot
  • Setup CORS agar Vercel bisa akses
~3 hari
Phase 3
Activity Frontend (Vercel)
Build web app Activity yang jalan di dalam Discord iframe.
  • Init SDK: discordSdk.ready(), authorize user
  • Ambil Discord user ID dari SDK
  • Fetch koleksi kartu dari VPS API
  • Tampilkan kartu user dalam UI (grid, animasi flip, dll)
  • Deploy ke Vercel (free)
~1 minggu
Phase 4
Integrasi & Testing
Sambungkan semua komponen dan test end-to-end di Discord.
  • Test Activity di Discord (buka via voice channel)
  • Verifikasi data koleksi muncul dengan benar
  • Handle error state (user belum punya kartu, API down, dll)
  • Update README dan announce ke server
~3 hari

Contoh Kode

FastAPI — VPS (api.py)

from fastapi import FastAPI from fastapi.middleware.cors import CORSMiddleware from data import load_data, get_user app = FastAPI() app.add_middleware(CORSMiddleware, allow_origins=["*"]) @app.get("/user/{user_id}/collection") def get_collection(user_id: str): data = load_data() user = get_user(data, user_id) return {"collection": user["collection"]}

Discord Activity — Vercel (main.js)

import { DiscordSDK } from "@discord/embedded-app-sdk"; const sdk = new DiscordSDK("CLIENT_ID"); await sdk.ready(); // Authorize & get user const { code } = await sdk.commands.authorize({ ... }); const userId = sdk.instanceId; // Fetch koleksi dari VPS const res = await fetch(`https://api.idy.gg/user/${userId}/collection`); const { collection } = await res.json();

Risiko & Mitigasi

Risiko Level Mitigasi
RAM VPS habis (1GB) Tinggi Monitor usage, pertimbangkan upgrade ke 2GB ($3-5/bln)
Discord Activity perlu approval Sedang Untuk server sendiri tidak perlu approval; butuh approval hanya untuk publik
CORS issue antara Vercel & VPS Sedang Konfigurasi CORS di FastAPI dengan benar
data.json race condition Rendah FastAPI dan Bot baca/tulis file yang sama — gunakan file lock atau migrate ke SQLite

Duel System (Real-time)

// Game Flow Buka Activity → Masuk queue → Match ditemukan → Draw 5 kartu random dari koleksi → Pilih 1 kartu (timer 60 detik) → Reveal — rarity lebih tinggi menang round → Round 2, Round 3 (Best of 3 — kartu baru tiap round) → Menang 2 round → Simpan ke duel_wins/losses bot

Backend
FastAPI WebSocket Server (VPS)
  • Matchmaking queue — pasangkan 2 player yang buka Activity
  • Game room — sync state antara 2 player via WebSocket
  • Game logic — BO3, timer server-side, scoring, reveal
  • API endpoint — simpan hasil ke data.json bot
~1 minggu
Frontend
Duel UI (React)
  • waiting — animasi mencari lawan
  • selecting — tampilkan 5 kartu, pilih 1, countdown timer
  • revealing — animasi reveal kedua kartu
  • round_end — skor sementara (misal 1–0)
  • game_end — layar menang/kalah, update stats
~1 minggu

Rules


Rule Detail
Format Best of 3 (BO3) — menang 2 round duluan
Hand size 5 kartu random dari koleksi per round (re-draw tiap round)
Syarat main Harus punya minimal 5 kartu di koleksi
Timer 60 detik per round — tidak pilih = auto-lose round
Matchmaking Siapapun yang buka Activity masuk queue
Hasil Masuk ke duel_wins / duel_losses di bot stats
